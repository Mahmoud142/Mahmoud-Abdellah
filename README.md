## 🖥️ Run the Portfolio Locally

This portfolio website is built with **React**, **TypeScript**, and **Vite**.

**Prerequisites:** Node.js 18+ · npm 9+

```bash
# Install dependencies
npm install

# Start development server
npm run dev
# → http://localhost:5173

# Build for production
npm run build
```

**Deployment:** Optimized for [Vercel](https://vercel.com) — Framework preset: `Vite`, Output: `dist`.

> If GitHub API requests fail (rate limits), the app automatically falls back to static data in `src/data/github.ts`.
